# Regeln der FST AUD 25

Damit zwölf Leute gleichzeitig an einem Repository arbeiten können, halten wir uns an ein paar Regeln.

1. Nie direkt auf `main` arbeiten, immer Branch und Pull Request.
2. Ein Branch für ein Thema. Kleine Pull Requests sind schneller geprüft.
3. Commit-Nachrichten sagen, was sich geändert hat, also „Tippfehler in der PID-Formel korrigiert“ statt „update“.
4. Nur eigene Dateien bearbeiten, außer es ist abgesprochen.
5. Reviews sind freundlich und konkret.
6. Keine Passwörter oder privaten Daten ins Repository, es ist öffentlich.

Branch-Namen kurz und klein geschrieben, zum Beispiel `steckbrief-max-m` oder `thema/03-sensoren`.

Die Anleitung steht unter https://yourworstdream.github.io/FSTAUD25/.
